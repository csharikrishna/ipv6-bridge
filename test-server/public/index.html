How to Test the Bridge

1. Start the IPv6 Bridge

cd ipv6-bridge
npm start

2. Start This Test Server

cd test-server
node server.js

3. Test IPv4 Directly (No Bridge)

Open browser and access this server directly via IPv4. You should see "IPv4" in the server info.

4. Test IPv6 Directly (No Bridge)

Open browser and access this server directly via IPv6. You should see "IPv6" in the server info.

5. Test Through Bridge (IPv4-only Networks)

Configure your system/browser proxy to localhost:8080 (the bridge). Then access the IPv4 endpoint. The bridge will translate your request to IPv6. You should still see "IPv4" in the logs because the test server sees the translated IP.

What You'll Learn
